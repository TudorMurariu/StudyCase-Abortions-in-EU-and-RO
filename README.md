# Study on Abortion Trends  in  the ​European Union

### In this study I tried to answer the following questions:​
1. How have abortion rates changed over time across EU countries?​

2. How do EU countries rank in terms of abortion numbers?​

3. Is there a correlation between the natality and the number of abortions?​

4. How do demographics (age) affect abortion rates?​

5. Do major events or new legislation impact the number of abortions?​

​
